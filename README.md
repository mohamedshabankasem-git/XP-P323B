# XP-P323B Printer

تطبيق Android مبني باستخدام Flutter ومخصص للطباعة على طابعة Xprinter XP-P323B.

## الوظائف الحالية

- واجهة عربية RTL بسيطة تتكون من صفحتين: **المشاركة** و**الإعدادات**.
- استقبال الصور وملفات PDF والنصوص من قائمة مشاركة Android.
- بدء الطباعة تلقائياً بعد استقبال المشاركة إذا كانت الطابعة متصلة؛ ويمكن إعادة الطباعة من صفحة المشاركة.
- الاتصال بالطابعة عبر Bluetooth أو USB OTG، مع حفظ آخر طابعة ومحاولة استعادة الاتصال.
- اختيار عرض الورق 58 أو 80 مم؛ الحد الأقصى الفعلي للطباعة في XP-P323B هو 72 مم (576 نقطة).
- اختيار محاذاة الطباعة: يمين أو منتصف أو يسار، مع حفظ الاختيار وتطبيقه على المحتوى المشترك.
- تحويل الصور والنصوص وصفحات PDF إلى بيانات ESC/POS raster أحادية اللون.

## البناء والتحقق

من جذر المشروع:

```sh
bash scripts/prepare_android.sh
flutter pub get
flutter analyze
flutter test
```

لبناء نسخة Release مخصصة لمعمارية ARM64 فقط:

```sh
flutter build apk --release --target-platform android-arm64
```

ينتج ملف APK واحد يحتوي على مكتبات `arm64-v8a` فقط:

```
build/app/outputs/flutter-apk/app-release.apk
```

هذه النسخة مناسبة لمعظم هواتف Android الحديثة ذات المعالج 64-bit، ولا تشمل `armeabi-v7a` أو `x86_64`.

في GitHub Actions يُرفع الملف كـ artifact باسم `xp-p323b-arm64-v8a-release` بعد نجاح التحليل والاختبارات والبناء.
للتطوير والاختبار فقط يمكن استخدام:

```sh
flutter build apk --debug
```

## ملاحظات الاتصال والطباعة

- يجب إقران طابعة Bluetooth من إعدادات Android أولاً، ثم منح صلاحية Bluetooth للتطبيق. إذا كان Bluetooth مغلقاً، يطلب التطبيق تشغيله من نافذة تأكيد Android النظامية؛ لا يفعّله بصمت.
- الاقتران وحده لا يعني وجود جلسة طباعة نشطة؛ يجب الاتصال بالطابعة من قسم **إدارة الطابعة** داخل الإعدادات.
- USB يتطلب هاتفاً يدعم USB Host/OTG وموافقة Android على صلاحية USB.
- إذا وصلت مشاركة دون اتصال بالطابعة، تبقى العناصر في صفحة المشاركة ويمكن إعادة طباعتها بعد الاتصال.
- طباعة الصور وPDF والنصوص تستخدم ESC/POS raster. يلزم اختبار وضوح العربية والهوامش والتباين على الطابعة الفعلية قبل اعتماد إصدار إنتاجي.

## مواصفات الطابعة المرجعية

أقصى عرض طباعة حسب مواصفات XP-P323B هو 72 مم (576 نقطة) بدقة 203 DPI. راجع دليل الطابعة وإعدادات النسخة الموجودة لديك للتأكد من توافق أوضاع الطباعة.
