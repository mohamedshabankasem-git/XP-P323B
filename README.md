# XP-P323B Printer

تطبيق Flutter مخصص لطابعة Xprinter XP-P323B لطباعة ملصقات المنتجات والفواتير.

## ما تم تنفيذه

- واجهة عربية RTL لأقسام الملصقات والفواتير والطابعة والمشاركة.
- جسر Android Native لاكتشاف أجهزة Bluetooth المقترنة وأجهزة USB OTG والاتصال والإرسال الخام.
- استقبال Android Share intents للصور وPDF والنصوص.
- تحويل الصور المشتركة إلى صورة حرارية أحادية اللون بعرض أقصى 576 نقطة، ثم إرسالها بأمر ESC/POS raster.
- تحويل النصوص المشتركة إلى صورة باستخدام محرك Flutter مع اتجاه RTL، ثم إرسالها للطباعة.
- تحويل صفحات PDF (حتى 40 صفحة في الملف الواحد) إلى صور PNG بعرض 576 نقطة على Android، ثم إرسال كل صفحة كصورة حرارية.
- إنشاء ملصقات 50×30 مم بأمر TSPL BITMAP؛ اسم المنتج والسعر يُشكّلان عربياً عبر Flutter، والباركود يُطبع بأمر TSPL.
- رسم الفواتير العربية RTL كصورة حرارية وإرسالها بأمر ESC/POS raster.

## البناء

ثبّت Flutter stable وAndroid SDK، ثم نفّذ:

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

إذا لم يوجد مجلد Android القياسي فنفّذ:

```sh
flutter create --platforms=android --org com.xpprinter .
```

## حدود النسخة الحالية

- طباعة الصور وصفحات PDF والنصوص المشتركة تستخدم ESC/POS raster. يلزم اختبار وضع ESC/POS على الطابعة الفعلية قبل الاعتماد عليه.
- طباعة النصوص والفواتير والملصقات تستخدم تشكيل Flutter/Skia واتجاه RTL؛ يلزم فحص شكل الحروف العربية فعلياً على الورق.
- الملصقات العربية تستخدم TSPL BITMAP والباركود الداخلي؛ لا تزال معايرة الأبعاد والهوامش وحجم الخط والتباين بحاجة إلى اختبار على الطابعة الفعلية.
- Bluetooth يستخدم RFCOMM/SPP، ويحتاج اختباراً على نسخة الطابعة الفعلية.
- USB يحتاج هاتفاً يدعم USB Host/OTG وموافقة Android على صلاحية USB.
- لا تعتبر هذه النسخة إصداراً إنتاجياً قبل اختبار الطباعة والاتصال على الجهاز الحقيقي.

## مواصفات الطابعة المرجعية

أقصى عرض طباعة حسب مواصفات XP-P323B هو 72 مم (576 نقطة) بدقة 203 DPI. تدعم الطابعة أوضاع TSPL وESC/POS وغيرها؛ راجع دليل الطابعة وإعدادات النسخة الموجودة لديك قبل اختيار وضع الطباعة.
